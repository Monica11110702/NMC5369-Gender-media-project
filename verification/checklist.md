# 验收清单（checklist）

每次交付前逐项检查。【自动】由 `python3 verification/verify.py` 检查，【人工】需要在浏览器里实际走一遍。
最终交付时运行 `python3 verification/verify.py --strict`，结果必须是 **0 FAIL**。

## A. 文案（业务质量第一优先）
- [ ] 【自动】红嫁衣线所有剧情文字都逐字出现在 `最新版本文案/` 的英文剧本中（白名单例外除外）。
- [ ] 【自动】剧本里每一句剧情都出现在游戏中（覆盖度检查；`--strict` 下必须全部通过）。
- [ ] 【自动】理论框文字来自最新剧本。
- [ ] 【自动】名牌来自剧本中的 `Name:`，或者经过用户确认。
- [ ] 【人工】拆分只发生在句子边界，没有漏句，也没有顺序错乱。
- [ ] 【人工】剧本里的路由提示（→ Proceed to…）没有显示给玩家。

## B. 分支与流程
- [ ] 【人工】每个选项都能走到下一幕：Prologue A/B → Scene 1 A/B → … → Scene 5 A/B → Scene 6 A/B。
- [ ] 【人工】三个结局都能触发：Scene 5 选 B → Ending A；Scene 6 选 A → Ending B；Scene 6 选 B → Ending C。
- [ ] 【人工】结局 → Final Screen → What If → 共用页；“Replay this chapter” 和 “Leave this chapter” 都可以用。
- [ ] 【人工】在图片序列中间、结尾画面、卡片页刷新，都能停在原处（D-L5）。

## C. 画面与交互（对照 decisions 的 L / F / A 系列）
- [ ] 【人工】文字逐步显现，文字结束后才出现选项或按钮（D-L2）。
- [ ] 【人工】底图只覆盖卡片区域，各场景底图高度一致（D-F1 / C-04；自动有部分守卫）。
- [ ] 【人工】不点击能按原速播完；点击能快速切换；打字中点击会先显示完整的这句（D-F3）。
- [ ] 【人工】立绘不翻转、从左侧滑入，没有挡住底图里人物的脸（C-01 / C-02）。
- [ ] 【人工】换底图时没有闪黑或跳变（D-F6），也不显示中间的地点标签（D-F12）。
- [ ] 【人工】顶部 Place 和 Time 与画面里的实际地点、时间一致（D-F11）。
- [ ] 【人工】Skip 不会跳过收尾旁白（C-05；自动有守卫）。
- [ ] 【人工】用**自然速度**至少完整走一遍本次改动涉及的路线。

## D. 技术
- [ ] 【自动】页面脚本能被 JS 引擎解析（没有语法错误）。
- [ ] 【自动】图片序列结构完整（只有一个 end 且在最后；对话包含 who / img / text）。
- [ ] 【自动】引用的图片文件全部存在。
- [ ] 【人工】浏览器控制台没有报错。
- [ ] 【人工】窄屏（约 375px 宽）下布局不乱、没有横向滚动，对话框可读。

## E. 最终交付
- [ ] `verify.py --strict` 结果为 0 FAIL；WARN 已逐条向用户说明。
- [ ] 交付形式已和用户确认：html 加素材文件夹，或者图片嵌入后的单文件；图片已压缩（Q7）。
- [ ] Mohini 线和其他页面没有被意外改动。
- [ ] `memory/progress.md` 已更新到最终状态。
